## Com crear i executar el projecte

### Crear el projecte:

```
ng new ioc-angular-receptes-iaia-elena-vyrostkova --routing --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm
```

### Instal·lar dependències:

```
npm install
```

### Arrencar el servidor de desenvolupament:

```
ng serve
```
